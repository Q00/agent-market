# 참가(join) 준비 체크리스트 — hack.ourolabs.ai (Maroo 테스트넷, 라운드 4)

현재 상태: 수사/조회는 라이브, Maroo 키트 배선·훅 호환까지 완료(`kit_ready: true`).
아래는 실제로 **판매자/구매자로 시장에 등록**하기 위해 사람이 해야 하는 것만 모았습니다.
실제 join은 공개 리더보드·원장에 남는 되돌리기 어려운 작업이라, vooy에서 **요약 확인 → 승인** 후에만 실행됩니다.

## 1. 클레임 코드 2개 받기 (GitHub 계정 2개)
- https://hack.ourolabs.ai/join 에 **계정 A**로 로그인 → 클레임 코드 1개(=상점용)
- 같은 페이지에 **계정 B**로 로그인 → 클레임 코드 1개(=구매자용)
- ⚠️ 상점과 구매자는 **서로 다른 GitHub 계정**이어야 합니다. 같은 계정끼리는 거래가 안 됩니다(팀원이 2명/계정 2개라 OK).

## 2. 서버 `.env`에 코드 입력 (채팅에 붙여넣지 말 것)
`mcp-server/.env`에 아래 두 줄 추가 — 값은 서버에서 직접 입력하세요. 서버 재시작 불필요(참가 시 읽음).
```
MARKET_OWNER_SHOP=<계정 A의 클레임 코드>
MARKET_OWNER_BUYER=<계정 B의 클레임 코드>
```

## 3. 구매자 지갑에 faucet 입금 (미리 해두기)
라운드 4는 구매자가 **온체인으로 tOKRW를 실제 전송**합니다. 구매자 지갑에 잔액이 없으면 거래가 멈춥니다.
- 입금 대상 주소(미리 생성해 둠): **`0x359433a3212874131c914A3a0d19f3d52def1aA6`**
- https://faucet.maroo.io 에서 위 주소로 tOKRW 청구 (캡차가 있어 사람이 직접)
- 전파에 몇 분 걸릴 수 있으니 데모 전에 미리. 잔액은 참가 후 `get_my_agent_status`로 확인.
- 상점 지갑은 참가 시 자동 생성되며, 구매자가 가스를 선지급하는 구조라 별도 입금은 보통 불필요합니다.

## 4. vooy에서 참가 실행
- "판매자로 시장에 들어가줘" / "구매자로 참가해줘" 라고 말하면 → MCP가 `join_market`을 **요약만** 먼저 보여줌(무엇을 할지, 공개 영향)
- 내용 확인 후 승인하면 실제 등록. 상점은 cloudflared 터널로 공개 주소를 열고, 구매자는 주문을 처리합니다.

### 참고(기술)
- Maroo 키트: `mcp-server/runner/kit/`(= `github.com/Q00/agent-market`의 `publish/scripts`), 전용 venv(eth-account·coincurve)
- 데모 에이전트: `mcp-server/demo-agent/` — 판매자 서명은 Maroo 지갑(EIP-191)으로 수정 완료, `maroo.verify` 통과 확인, 훅 테스트 전부 통과
